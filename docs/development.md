# Development and security

Node 24 is the selected LTS; dependencies are pinned in the lockfile. Set `DATABASE_URL` to a local `file:` SQLite path and `PORT` to an integer from 1 to 65535; defaults are `file:.data/collection.db` and `3000`. `SITE_URL` is an HTTP(S) origin used for canonical links and sitemap; it defaults to `http://localhost:<PORT>`. Migration rejects non-file URLs and URL queries. `npm run dev` and Instagram commands load `.env` if present, with existing environment variables taking precedence. Migration uses the environment passed to it and does not load `.env`; set `DATABASE_URL` explicitly if targeting another database. Run commands from the repository root. `db:migrate` is repeatable. Local databases live in ignored `.data/`. The runtime requires an existing database and R2 read-only credentials, enables SQLite `query_only`, and has no write routes.

`npm test` exercises real route responses with an in-memory SQLite database and Testing Library. `npm run typecheck`, `npm run lint`, `npm run test:coverage`, `npm run build`, and `npm run test:e2e` run the individual checks. The browser suite starts and stops its own test-only server on port 3107, with an in-memory database, synthetic fixtures and a fake image service; it uses Playwright's matching headless Chromium shell. Install it with `npx playwright install chromium --only-shell` if needed. `npm run verify` combines the final checks after review.

HTML responses use `public, max-age=0, s-maxage=300, stale-while-revalidate=60`; errors and signed redirects use `no-store`. Content-hashed assets use one-year immutable caching. Change the URL whenever bytes change. CSP denies everything by default and permits same-origin styles and images from the configured R2 endpoint; templates escape data and image links are limited to content-hashed media paths. Never put credentials or untrusted raw HTML in public data. Local header tests do not prove CDN behavior, invalidation, or production image delivery. Those remain deployment work. See [Instagram importing](instagram-access.md) for the separate write workflow.
