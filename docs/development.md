# Development and security

Node 24 is the selected LTS; dependencies are pinned in the lockfile. Set `DATABASE_URL` to a local `file:` SQLite path and `PORT` to an integer from 1 to 65535; defaults are `file:.data/demo.db` and `3000`. Migration and seed reject non-file URLs and URL queries. Run commands from the repository root. `db:migrate` is repeatable; `seed:demo` replaces only the `esimerkki` fixture and its images. Local databases and copied demo media live in ignored `.data/`; source fixtures are synthetic and tracked. Do not use the demo seed on a database containing a post with that key. The runtime requires an existing database, enables SQLite `query_only`, and has no write routes.

`npm test` exercises real route responses with an in-memory SQLite database and Testing Library. `npm run typecheck`, `npm run lint`, `npm run test:coverage`, `npm run build`, and `npm run test:e2e` run the individual checks. Build before the browser suite; it starts and stops its own server on port 3107, migrates and seeds the separate `.data/e2e.db` test database, and uses Playwright's matching headless Chromium shell. Install it with `npx playwright install chromium --only-shell` if needed. `npm run verify` combines the final checks after review.

HTML responses use `public, max-age=0, s-maxage=300, stale-while-revalidate=60`; errors use `no-store`. Content-hashed local assets use one-year immutable caching. Change the URL whenever bytes change. CSP denies everything by default and permits only same-origin images and styles; templates escape data and image links are limited to local media paths. Never put credentials or untrusted raw HTML in public data. Local header tests do not prove CDN behavior, invalidation, or production image delivery. Those remain deployment work.
