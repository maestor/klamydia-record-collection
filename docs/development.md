# Development and security

Node 24 is the selected LTS; dependencies are pinned in the lockfile. Set `DATABASE_URL` to a local `file:` SQLite path and `PORT` to an integer from 1 to 65535; defaults are `file:.data/collection.db` and `3000`. `SITE_URL` is an HTTP(S) origin used for canonical links and sitemap; it defaults to `http://localhost:<PORT>`. Migration and seed reject non-file URLs and URL queries. `npm run dev` and Instagram commands load `.env` if present, with existing environment variables taking precedence. Migration and seed use the environment passed to them and do not load `.env`; set `DATABASE_URL` explicitly if targeting another database. Run commands from the repository root. `db:migrate` is repeatable. Local databases and copied demo media live in ignored `.data/`; source fixtures are synthetic and tracked. The runtime requires an existing database, enables SQLite `query_only`, and has no write routes.

For a separate demo database, run `DATABASE_URL=file:.data/demo.db npm run db:migrate` followed by `DATABASE_URL=file:.data/demo.db npm run seed:demo`. Start it with `DATABASE_URL=file:.data/demo.db npm run dev`. The seed requires an explicit target, refuses the default collection database and replaces only the `esimerkki` and `esimerkki-02`–`esimerkki-27` fixtures and their images. Do not seed a database containing posts with those keys. Browser tests use their own fixture database.

`npm test` exercises real route responses with an in-memory SQLite database and Testing Library. `npm run typecheck`, `npm run lint`, `npm run test:coverage`, `npm run build`, and `npm run test:e2e` run the individual checks. Build before the browser suite; it starts and stops its own server on port 3107, migrates and seeds the separate `.data/e2e.db` test database, and uses Playwright's matching headless Chromium shell. Install it with `npx playwright install chromium --only-shell` if needed. `npm run verify` combines the final checks after review.

HTML responses use `public, max-age=0, s-maxage=300, stale-while-revalidate=60`; errors use `no-store`. Content-hashed local assets use one-year immutable caching. Change the URL whenever bytes change. CSP denies everything by default and permits only same-origin images and styles; templates escape data and image links are limited to local media paths. Never put credentials or untrusted raw HTML in public data. Local header tests do not prove CDN behavior, invalidation, or production image delivery. Those remain deployment work. See [Instagram access and local importing](instagram-access.md) for the separate write workflow.
